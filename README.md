## Hi, I'm Nilton 👋

Application developer in training (**Informatiker EFZ Applikationsentwicklung**, IMS at bwd Bern and gibb) with a Berufsmaturität in business.
I like building apps that people actually use, from the first idea and concept to a working release. Most of my projects are web apps with React and TypeScript, and mobile apps with React Native.

I use AI tools like Claude as part of my workflow: I plan the features, review the code and test what goes into the app.
